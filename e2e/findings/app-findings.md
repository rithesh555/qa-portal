## Suggestions (ux-reviewer, not bugs)

- Save and add another: keep the suite (and labels) instead of resetting.
- Log defect: prefill Expected from the step's expected result.
- Defect status history: hide the strip until there are two steps.
- Test case page: put the History tab in the URL; breadcrumb back to the filtered list.
- Empty project overview and Releases: add New release / Add test cases calls to action.
- New user: Copy button for the temporary password.
- Suite tree: child suite missing its folder icon.
- Defects list: rename "Found in" column (shows "Logged by hand") to Source.
- Reports charts: axis tick labels ~8px, too small.
